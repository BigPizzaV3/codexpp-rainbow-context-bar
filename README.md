# 彩虹上下文进度条

将输入区的上下文用量圆环改为彩虹渐变进度条，实时显示实际用量百分比，保留原有悬停详情。

## 安装

在 Codex++ 管理器打开「拓展 → 社区拓展」，搜索 `rainbow-context-bar` 点安装；
或从 [Releases](https://github.com/BigPizzaV3/codexpp-rainbow-context-bar/releases) 下载 `rainbow-context-bar-v<版本>.zip`，解压到 Codex++ 的拓展目录。

## 需要的能力

| 能力 | 内容 |
| --- | --- |
| 页面脚本 | `renderer.js` |
